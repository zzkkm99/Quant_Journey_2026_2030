# Application Evidence

This directory organizes evidence for future graduate applications. It is not
an official checklist and must be updated against the target program's
official requirements in the relevant application cycle.

## Evidence standard

For each course or skill, keep the course name, credit hours, syllabus topics,
grade when available, and the source of the information. Do not label a
course as an official equivalent without confirmation from the receiving
program.
