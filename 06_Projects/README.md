# Quantitative Finance Projects

This directory contains completed and in-progress projects that connect
mathematics, programming, numerical methods, and financial applications.

Each project must include a runnable command, a clear result, validation, and
limitations before it is marked complete.

## Project sequence

1. Monte Carlo fundamentals
2. Analytical option pricing
3. Monte Carlo option pricing
4. Numerical methods for finance
5. Implied volatility and volatility surfaces
6. C++ pricing engine
